# Techfest 2026 — An Aetherial Renaissance
> **Web Platform for the 30th Edition of Techfest, IIT Bombay**

---

## 🌌 About Techfest, IIT Bombay

Established in 1998, **Techfest** is the annual science and technology festival of the **Indian Institute of Technology (IIT) Bombay**. Recognized as **Asia's Largest Science and Technology Festival**, Techfest serves as a premier platform for tech enthusiasts, innovators, researchers, and industry leaders across the globe.

### Key Highlights
- **180,000+** Annual Footfall
- **30th Milestone Edition** (December 2026)
- **300+** Events, Competitions & Keynotes
- **20+** Countries Participating Worldwide
- **Flagship Attractions**: Robowars, International Exhibitions, Technoholix, Keynote Summits, and Hands-on Workshops.

---

## 🚀 Key Features of this Platform

- **Interactive UI**: Sections showcasing Competitions, Exhibitions, Workshops, Speakers, and Sponsors.
- **Live Event Countdown**: Real-time timer counting down to Techfest 2026 at IIT Bombay.
- **Database Ready**: Supabase integration with migration schemas for storing user registrations and festival data.
- **Modern Design**: Designed with Tailwind CSS featuring custom typography (*Cormorant Garamond* & *Space Grotesk*).
- **Type Safe**: Fully typed components built with React 18, Vite, and TypeScript.

---

## 🛠️ Tech Stack

- **Frontend**: [React 18](https://react.dev/), [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/), [PostCSS](https://postcss.org/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Backend / Database**: [Supabase](https://supabase.com/)
- **Linting**: [ESLint](https://eslint.org/)
